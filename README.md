# Maxget 产品工作台

一个无需后端、无需 API 密钥的产品经理工作台 MVP。围绕需求收集、结构化分析、低保真原型和 PRD 输出组织工作流。

## 本地运行

直接用浏览器打开 `index.html` 即可。也可以从仓库根目录启动任意静态文件服务器，例如：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。项目没有 npm 依赖、构建步骤或外部 AI 服务。

## 功能

- **总览与需求池**：查看需求进展，创建需求，按状态筛选并搜索。
- **需求洞察**：围绕核心问题、产品机会、衡量指标和下一步研究建议形成结构化分析。内容由本地模板规则生成，仅用于演示和启发，不是 AI 结论。
- **原型工作台**：根据所选需求生成可预览的低保真页面概念，并切换桌面/移动端画布。
- **需求文档**：编辑需求概述、目标、范围、流程、指标和风险；内容自动保存在当前浏览器，可导出 Markdown。

需求和文档存储在当前浏览器的 `localStorage` 中，不会同步到其他设备或上传到服务器。清理浏览器站点数据会删除本地修改。默认演示数据可在浏览器清除 `maxget.requirements.v1` 后恢复。

## 部署到 Vercel

这是纯静态站点，不需要构建命令。可在 Vercel 导入 GitHub 仓库 `haoxinli-bit/max-get`，将 Framework Preset 设为 **Other**，Build Command 留空，Output Directory 设为 `.`，然后部署。

也可以在已安装并登录 Vercel CLI 的环境中，从仓库根目录运行：

```sh
vercel
vercel --prod
```

首次部署时按 CLI 提示关联 Vercel 账号和项目。部署成功后访问 CLI 返回的 URL，确认页面可以正常加载。
